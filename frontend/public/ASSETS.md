# Ocular interface assets

The monogram, sample-output mockup, and classroom illustration were generated
with the built-in ImageGen tool for this interface. All generated classroom
imagery is illustrative: it is not a research input, real footage, model output,
or accuracy evidence.

Design reference: [Samfund by Ofspace UX/UI](https://dribbble.com/shots/26295527-Samfund-AI-Driven-Fintech-Support-Landing-Page-UI-Design).
The layout adapts its centered hero, neutral surfaces, dark pill controls, and
pastel card composition to the existing classroom review product. No Samfund
branding, photos, testimonials, or performance claims were copied into the app.
Lucide supplies the existing interface icon set.

## Monogram

File: [brand/ocular-logo-yellow.png](brand/ocular-logo-yellow.png), 1254 × 1254,
transparent PNG. Used in the header, footer, favicon, and Apple touch icon.
The user-supplied visual reference establishes the thick circular ring, rounded
lower-right terminal, and separate accent dot. The final requested accent is
butter yellow, matching the website's `--butter` palette, with a dark slate ring.
Generated and edited using the built-in ImageGen tool. The earlier aperture
monogram remains saved as an unused prior variant.

Generation prompt: “Use the supplied reference's bold circular ring, circular
counter, short rounded lower-right terminal, and detached round accent dot.
Use dark slate for the ring; flat solid colors, smooth edges, no wordmark,
text, shadow, gradient, or mockup. Center one mark on a transparent square.”

Final edit prompt: “Change only the separate lower-right dot to pale butter
yellow #F5ED9C. Preserve the dark-slate ring #222B37, circular counter, rounded
terminal, proportions, position, scale, and transparent margins. Preserve real
alpha transparency behind the artwork and inside the circle. No green, teal,
gold, gradients, lighting, shadows, textures, text, wordmark, or background.”

## Student-writing hero portrait

File: [images/student-writing-portrait.webp](images/student-writing-portrait.webp),
1024 x 1536 WebP (181,952 bytes). Generated with the built-in ImageGen tool using
the user's supplied poster as a composition reference, then encoded as WebP.
The second hero card displays the photograph edge to edge with responsive
`object-fit: cover` and a heading overlay. At the user's request, the visible
AI-generated labels were removed from the hero, session example, and care images;
image provenance remains documented here.
No poster text or logo was copied. This is illustrative imagery, not an analysis
input, footage, model output, or accuracy evidence.
