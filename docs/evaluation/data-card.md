# CP2 data card: Pointing04 moderate poses, version 1

**Acquired 22 October 2026.** [Author-hosted database description and permission](http://crowley-coutaz.fr/Head%20Pose%20Image%20Database.html); [original archive](http://crowley-coutaz.fr/HeadPoseDataSet/HeadPoseImageDatabase.tar.gz). The author page permits any purpose with citation: N. Gourier, D. Hall, J. L. Crowley, *Estimating Face Orientation from Robust Detection of Salient Facial Features*, Pointing 2004 / ICPR Workshop on Visual Observation of Deictic Gestures, Cambridge, UK. This is a custom attribution condition, not an inferred CC license. It supports the small public sample set and attributed contact sheet. BIWI remains unacquired; its planned role is replaced for this initial baseline, not silently claimed as completed.

**Integrity and acquisition.** The archive is 28,512,828 bytes, SHA256 `5629cb428f38c65ba0220f480ea53ba859f56fbfc5a34e7396a981f0485ed209`. `python scripts/prepare_data.py` downloads at most 40 MiB, checks this exact hash before safe JPEG-only extraction, and regenerates the manifests. The source host's HTTPS certificate mismatches its hostname; HTTP is used explicitly. The hash pins the reviewed bytes and detects later changes but does not authenticate the first HTTP retrieval. No insecure TLS override or downloaded executable is used. The archive contains 2,790 pose images plus 30 duplicate frontal convenience copies; `Front/` duplicates are excluded.

**Population and capture.** Fifteen people, two 93-pose series per person, 384 x 288 color JPEGs. The source describes neutral, uncluttered backgrounds, some glasses, and seated subjects looking toward prescribed room markers approximately two meters from a Sony CCD EVI-D31 camera. Original pose angles are nominal targets, not continuous sensor measurements; no precision beyond the annotations is claimed. Every selected image was decoded to check dimensions, and cardinal source poses were visually checked for angle signs. No detector predictions were used to create labels.

**Label contract and selection.** All labels refer to the subject's own left/right in unmirrored input. Set canonical `yaw = -source_pan`, `pitch = -source_tilt`; positive yaw faces image right and positive pitch is down. Source documentation contains a transposed pan/tilt table, so filename definitions, the explicit vertical -90 = bottom statement, and inspected cardinal examples establish this conversion. General bins: down at pitch >=30 degrees (wins mixed poses); otherwise left at yaw >=30, right at yaw <=-30, forward at absolute yaw/pitch <=15. Upward-only pitch <-15 and gaps between these nominal bins are excluded. Bins are ground-truth definitions fixed before prediction, independent of configurable detector ratio thresholds.

The predetermined CP2 subset uses both series at pitch 0 and yaw -60,-45,-30,-15,0,15,30,45,60, plus series 1 only at pitch 30/60 and yaw -15,0,15. This yields six examples per class per subject. Series 2 downward poses, upward poses, mixed extreme turns, and profiles beyond 60 degrees are outside this initial subset. This deliberate moderate-angle scope must accompany reported results; it is not an official full-dataset benchmark. No training split is needed for the untrained geometric baseline. Subjects, source series, IDs, paths, and pixel hashes are checked for cross-split leakage before filtering validation. The test manifest is fixed and has not been scored or used to choose thresholds.

**Preparation and limitations.** Keep original pixels unchanged; prediction and evaluation share the actual preprocessing module under `src/gaze/`. The contact sheet downsizes images only for display; those resizes never become evaluation inputs. Preprocessing evidence describes the configured steps actually applied. The checked-in twenty examples span five validation subjects and four directions; their labels and SHA256 hashes appear in `data/annotations/samples.json`. All 360 selected files decode at 384 x 288. Full data stays in ignored `data/raw/`; manifests refer to either checked-in examples or those local originals. Single-person posed laboratory images cannot establish classroom, lighting, demographic, occlusion, distant-face, tracking, event, writing, or multi-person performance. Missed faces and unknown predictions must count as failures in overall classification scores. Separate video evidence supports only its explicitly measured claims.
