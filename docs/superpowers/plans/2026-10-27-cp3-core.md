# CP3 Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Produce the runnable pipeline and reproducible evidence required for the CP3 hand-in.

**Architecture:** Reuse the pinned head detector and 6DRepNet360 adapters for automatic camera-relative direction without seat calibration. Keep calibrated seat-relative video review separate. Share inference between the command-line runner and evaluator; generate report artifacts from saved measurements.

**Tech Stack:** Python 3.12, NumPy, OpenCV, MediaPipe baseline, ONNX Runtime CPU, Matplotlib.

**Spec:** [CP3 requirements and rubric](../../checkpoints/cp3-hand-in/README.md).

- Timing and accuracy must use matching inputs and record the exact frozen configuration.
