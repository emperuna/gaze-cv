# Pointing04 sample attribution

These twenty unchanged JPEG images come from the Pointing04 Head Pose Image Database by Nicolas Gourier, Daniela Hall, and James L. Crowley, PRIMA Team, INRIA Rhone-Alpes. They are validation examples; filenames retain the original nominal tilt/pan annotations.

The [author-hosted database page](http://crowley-coutaz.fr/Head%20Pose%20Image%20Database.html), accessed 22 October 2026, permits any purpose provided the following work is cited:

N. Gourier, D. Hall, J. L. Crowley. *Estimating Face Orientation from Robust Detection of Salient Facial Features*. Proceedings of Pointing 2004, ICPR, International Workshop on Visual Observation of Deictic Gestures, Cambridge, UK.

The permission is an attribution condition supplied by the dataset authors, rather than a standardized Creative Commons or code license. See the [data card](../../../docs/evaluation/data-card.md) for acquisition integrity, image provenance, and limitations. Face photographs remain identifiable data; the project uses them for head direction, without identity recognition.
