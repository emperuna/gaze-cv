# Future session configuration

This folder is reserved for configuration that becomes necessary during development. It currently contains only this README. No configuration files, loader, or calibrated defaults exist yet.

| Planned settings | When to introduce them |
| --- | --- |
| Direction thresholds | When baseline experiments establish which settings need adjustment. |
| Fixed seat regions | Around CP3, after the camera view and region definitions are established. |
| Movement duration, repetitions, and observation periods | Around CP4, when temporal behavior is implemented and evaluated. |

The initial five-image spike and contact sheet do not require a general session configuration system. Simple input and output options can be added to their commands when implementation begins.

Choose the configuration format and validation rules when actual behavior needs them. Derive defaults from development experiments, record the settings used for evaluation, and keep seat references separate from student identities.
