# Outputs

`evidence/` contains a small attributed contact sheet, reviewed preprocessing/image/video examples, and selected reproducible validation/timing summaries. These are limited technical evidence, not proof of academic submission, cheating, final test performance, or classroom reliability.

Full annotated videos, per-frame/session JSON, and exploratory run folders belong in ignored `runs/`. Local caches and verification environments belong in ignored `.work/` at the project root. Use new video run directories; source assets must never be overwritten. Keep all local writes on F: during this session. See [the checkpoint report](../docs/checkpoints/cp2-progress.md) for provenance and limitations.
